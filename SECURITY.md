# Security Policy

Please do not report security vulnerabilities through public issues,
discussions or pull requests.

This layer only packages the iceoryx2 sources for Yocto builds. Report
vulnerabilities, whether in iceoryx2 itself or in this layer, as described in
the [iceoryx2 security policy](https://github.com/eclipse-iceoryx/iceoryx2/security/policy).
